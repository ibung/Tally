# Tally
Tally adalah aplikasi mobile untuk membantu pengguna mencatat, memantau, dan mengelola keuangan pribadi sehari-hari. Aplikasi terinspirasi dari Sepran Expense Manager, dengan pengalaman pencatatan transaksi yang praktis, pengelolaan banyak wallet, serta fitur kuota pengeluaran yang dapat dikontrol pengguna.
